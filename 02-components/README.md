# 02 - Components

**Topic:** Functional and class components

## Learning Objectives
- Understand functional components
- Learn about class components (legacy)
- Understand component composition
- Know when to use each component type

## Topics Covered
- Functional components
- Class components (basics)
- Component composition
- Reusable components
- Component naming conventions

## Exercises

1. **Create Functional Components**
   - Build several simple functional components
   - Example: Header, Footer, Card, Button

2. **Compose Components**
   - Create a layout using multiple components
   - Build a component hierarchy

3. **Create Reusable Components**
   - Build a generic Card component
   - Build a Button component with variations

4. **Component Naming**
   - Practice proper React naming conventions

## Key Concepts

- **Functional Components:** JavaScript functions that return JSX
- **Class Components:** ES6 classes that extend React.Component (legacy)
- **Component Composition:** Building UIs from smaller, reusable components
- **Single Responsibility:** Each component should do one thing well
