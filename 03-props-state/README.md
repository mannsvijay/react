# 03 - Props and State

**Topic:** Props passing and state management

## Learning Objectives
- Understand props and how to pass data to components
- Learn state and how to manage component data
- Understand lifting state up
- Know the difference between props and state

## Topics Covered
- Props fundamentals
- Passing data via props
- Default props
- Prop types
- Component state with useState
- Lifting state up
- Two-way data binding

## Exercises

1. **Pass Props to Components**
   - Create parent and child components
   - Pass data from parent to child
   - Use destructuring for props

2. **Manage State**
   - Create a counter component using useState
   - Build a form with input state
   - Update state on user interactions

3. **Lift State Up**
   - Create multiple components that share state
   - Move state to parent component
   - Update siblings through parent callbacks

4. **Prop Validation**
   - Add PropTypes for type checking
   - Set default props

## Key Concepts

- **Props:** Read-only data passed from parent to child
- **State:** Data that changes over time and triggers re-renders
- **Lifting State:** Moving state to the nearest common ancestor
- **Immutability:** State should never be modified directly
