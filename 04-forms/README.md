# 04 - Forms

**Topic:** Form handling and validation

## Learning Objectives
- Build controlled and uncontrolled forms
- Handle form events
- Implement form validation
- Handle file uploads
- Create reusable form components

## Topics Covered
- Controlled components
- Uncontrolled components
- Form events (onChange, onSubmit)
- Validation strategies
- Error handling
- File uploads
- Form libraries (optional)

## Exercises

1. **Build a Controlled Form**
   - Create a login form with email and password
   - Manage form state
   - Display form values

2. **Form Validation**
   - Add client-side validation
   - Show error messages
   - Disable submit button when invalid

3. **Complex Form**
   - Multi-field form (name, email, phone)
   - Dropdown and textarea inputs
   - Radio buttons and checkboxes

4. **Form Submission**
   - Handle form submission
   - Prevent default behavior
   - Submit data to an API (optional)

## Key Concepts

- **Controlled Components:** React state is the source of truth
- **Uncontrolled Components:** DOM is the source of truth (use refs)
- **Form Validation:** Check data before submission
- **User Feedback:** Show validation errors and success messages
