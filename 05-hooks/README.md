# 05 - Hooks

**Topic:** React Hooks (useState, useEffect, useContext, etc.)

## Learning Objectives
- Master useState hook
- Understand useEffect lifecycle
- Learn useContext for prop drilling avoidance
- Understand useReducer for complex state
- Learn other useful hooks

## Topics Covered
- useState fundamentals
- useEffect for side effects
- useEffect cleanup
- useContext for global state
- useReducer for complex state
- useCallback and useMemo
- useRef
- Custom hooks introduction

## Exercises

1. **useState Patterns**
   - Counter with increment/decrement
   - Toggle state
   - Multiple state variables
   - Array/object state management

2. **useEffect Workflows**
   - Fetch data on component mount
   - Update title on state change
   - Poll API periodically
   - Cleanup side effects

3. **useContext**
   - Create a theme context
   - Provide theme values
   - Consume theme in nested components

4. **useReducer**
   - Build a form with useReducer
   - Manage complex state transitions
   - Handle form validation

## Key Concepts

- **Hooks:** Functions that let you use state and other React features
- **Rules of Hooks:** Only call hooks at the top  level, only in React functions
- **Dependencies:** useEffect dependency array controls when effects run
- **Cleanup:** Return a cleanup function from useEffect
