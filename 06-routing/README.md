# 06 - Routing

**Topic:** React Router implementation

## Learning Objectives
- Set up React Router
- Create navigation between pages
- Handle URL parameters
- Implement nested routes
- Create protected routes

## Topics Covered
- React Router setup
- BrowserRouter and Routes
- Route component
- Link and NavLink
- URL parameters
- Query strings
- Nested routes
- Route guards/protected routes
- Navigation hooks

## Exercises

1. **Basic Routing**
   - Create multiple pages (Home, About, Contact)
   - Set up React Router
   - Navigate between pages

2. **Dynamic Routes**
   - Create a product listing page
   - Add product detail page with URL params
   - Navigate to product details

3. **Nested Routes**
   - Create a dashboard with sub-routes
   - Build a settings page with tabs as routes
   - Nested layout components

4. **Protected Routes**
   - Create an authentication context
   - Implement protected routes
   - Redirect unauthenticated users

## Key Concepts

- **Router:** Manages navigation and URL state
- **Routes:** Define which component displays for each path
- **Link:** Client-side navigation without page reload
- **URL Parameters:** Dynamic segments in URLs
- **Route Guards:** Protect routes based on conditions
